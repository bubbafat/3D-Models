# 3D-Models

3D-printable models generated entirely by Autodesk Fusion Python scripts —
run a script in an empty design and it builds every part, checks itself, and
reports what it made.

| Folder | |
|---|---|
| [Cruise Ship](Cruise%20Ship) | Disney Cruise Line ship countdown, with three day-count cubes and a spare in the transom |
| [Monorail](Monorail) | Disney monorail countdown on a beam and pylons, sharing the ship's cubes |
| [ClaudeBridge](ClaudeBridge) | A Fusion add-in that lets another program — or an AI assistant — run scripts in Fusion and inspect the results |
